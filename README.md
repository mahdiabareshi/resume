# سایت رزومه mahdi dev — نسخه‌ی چندفایلی برای هاست (PHP)

ساختار پروژه:

```
├── index.html            صفحه‌ی اصلی (فقط مارک‌آپ)
├── assets/
│   ├── css/style.css     تمام استایل‌ها
│   └── js/app.js         تمام اسکریپت‌ها
├── api.php               بک‌اند (PHP ≥ 7.4) — محتوا، آمار، احراز هویت ادمین
├── data/                 داده‌های ذخیره‌شده (با .htaccess از وب مسدود است)
│   ├── data.json         محتوای عمومی سایت
│   └── (config.json بعد از تعیین رمز ساخته می‌شود — فقط hash)
└── .htaccess             هدرهای امنیتی + مسدودسازی فایل‌های حساس
```

## امنیت پنل ادمین

- رمز مدیر **هیچ‌جای کد وجود ندارد**. بار اول که پنل را باز کنی، فرم «تعیین رمز» می‌آید؛
  رمز فقط به‌صورت hash (bcrypt) در `data/config.json` ذخیره می‌شود.
- ورود: **۳ کلیک روی لوگوی سایت** → پنجره‌ی ورود → فقط رمز.
- بعد از ۵ رمز اشتباه، ۱۰ دقیقه قفل (سمت سرور).
- اگر رمز را فراموش کردی: از File Manager سی‌پنل فایل `data/config.json` را حذف کن؛
  دفعه‌ی بعد که پنل را باز کنی دوباره فرم «تعیین رمز» می‌آید.
- بخش «فراموشی رمز» عمداً حذف شده تا هیچ سرنخی از رمز در سایت نباشد.

## نصب روی هاست لینوکس (سی‌پنل)

1. وارد **cPanel** شو و **File Manager** را باز کن.
2. وارد پوشه‌ی `public_html` شو (اگر سایت در دامنه‌ی اصلی است؛ وگرنه زیرپوشه‌اش).
3. فایل `mahdi-portfolio.zip` را **آپلود** کن (دکمه‌ی Upload یا کشیدن‌ورهاکردن).
4. روی فایل زیپ راست‌کلیک → **Extract** → مسیر استخراج همان `public_html`.
5. زیپ را پاک کن. فایل‌های `index.html`، `api.php`، پوشه‌های `assets/` و `data/` باید
   مستقیماً داخل `public_html` باشند.
6. PHP هاست باید **۷.۴ یا بالاتر** باشد (در cPanel: MultiPHP Manager).
7. سایت را باز کن؛ برای مدیریت: ۳ کلیک روی لوگو → تعیین رمز (بار اول) → پنل.

### اگر چیزی ذخیره نشد (خطای write_failed)
پوشه‌ی `data` باید قابل نوشتن باشد: در File Manager روی پوشه‌ی `data` راست‌کلیک →
Permissions → عدد را `755` بگذار و «Recurse into subdirectories» را برای همه تیک بزن.

### نکته‌ی لوکال
روی کامپیوتر شخصی هم می‌توانی تست کنی (بدون PHP فقط حالت نمایشی با localStorage):
```
php -S 127.0.0.1:8080
```
و در مرورگر `http://127.0.0.1:8080` را باز کن. پنل ادمین و ذخیره‌ی دائمی فقط با PHP کار می‌کند.

## پشتیبان‌گیری
از File Manager هر چند وقت یک‌بار پوشه‌ی `data` را دانلود کن؛ تمام محتوای
پنل (پروژه‌ها، مهارت‌ها، تایم‌لاین، متن‌ها، آمار) همان‌جاست.
